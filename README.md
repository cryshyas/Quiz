## 📝 3. 문항 및 해설 수정 방법

문항은 디자인 코드(`index.html`)와 완전히 분리되어 **[`questions.js`](file:///c:/Users/user/Desktop/Quiz/questions.js)** 파일 하나에 모여 있습니다.

### 수정 예시:
[`questions.js`](file:///c:/Users/user/Desktop/Quiz/questions.js) 파일을 열고 해당 문항 블록의 텍스트를 수정합니다:
```javascript
{
  id: "A-1",
  stepName: "1단계: 사실 확인",
  question: "영화 속에서 리치는 B봇을 주로 어떤 용도로 사용했나요?",
  options: [
    "다른 친구들을 놀리고 짓궂은 장난을 찍는 용도", // 0번 보기
    "학교 도서관에서 친구들과 공부를 돕는 용도",     // 1번 보기
    "버려진 쓰레기를 줍고 교실을 청소하는 용도",     // 2번 보기
    "혼자 있는 친구에게 따뜻한 위로를 건네는 용도"   // 3번 보기
  ],
  answerEnc: _enc("0"), // 정답 번호 (0: 첫번째, 1: 두번째, 2: 세번째, 3: 네번째)
  hint: "리치가 복도에서 친구들을 쫓아다니며 B봇 카메라로 무엇을 촬영했는지 떠올려 보세요.",
  explanation: "리치는 B봇을 친구를 놀리고 괴롭히는 장난 영상 촬영용으로 잘못 사용했어요."
}
```
- 문항이나 보기를 수정할 때 따옴표(`" "`) 안의 글자만 고치시면 됩니다.
- 정답 번호를 바꾸려면 `_enc("0")` 안의 숫자(`"0"`, `"1"`, `"2"`, `"3"`)만 바꿔주시면 됩니다.

## 🚀 4. Firebase 처음 사용하는 선생님을 위한 배포 5단계 가이드

본 앱은 Firebase 설정 키가 없어도 브라우저에서 더블클릭하면 **로컬 오프라인 모드**로 100% 정상 작동하지만, 교실 21대 기기와 교사 대시보드를 실시간 연동하려면 **Firebase 무료 플랜**을 활용하는 것이 가장 좋습니다.

### 1단계: Firebase 프로젝트 생성 (2분)
1. 크롬 브라우저로 [Firebase 콘솔](https://console.firebase.google.com/)에 접속하여 구글 계정으로 로그인합니다.
2. **[프로젝트 추가]** 버튼을 클릭합니다.
3. 프로젝트 이름 입력 (예: `moral-escape-2026`) ➔ Google 애널리틱스는 '사용 안함' 체크 ➔ **[프로젝트 만들기]** 클릭.

### 2단계: Firestore 데이터베이스 활성화 (1분)
1. 콘솔 좌측 메뉴에서 **[빌드] ➔ [Firestore Database]** 클릭 ➔ **[데이터베이스 만들기]** 클릭.
2. 위치 설정: **`asia-northeast3 (서울)`** 선택.
3. 보안 규칙 시작 모드: **[테스트 모드에서 시작]** 선택 후 [사용 설정].

### 3단계: 익명 인증 활성화 (30초)
1. 콘솔 좌측 메뉴에서 **[빌드] ➔ [Authentication]** 클릭 ➔ **[시작하기]**.
2. **[로그인 방법]** 탭에서 **[익명]** 공급자를 찾아 클릭하고 **[사용 설정]**을 켠 후 [저장]합니다.

### 4단계: 설정 키를 `firebase-config.js`에 붙여넣기 (1분)
1. Firebase 콘솔 메인의 **톱니바퀴 아이콘(프로젝트 설정)** ➔ **[일반]** 탭 하단의 `내 앱`에서 **웹 아이콘(</>)**을 클릭합니다.
2. 앱 닉네임 입력 (예: `web-app`) ➔ **[앱 등록]**.
3. 화면에 나오는 `firebaseConfig` 객체 내용을 복사하여, 우리 프로젝트의 **[`firebase-config.js`](file:///c:/Users/user/Desktop/Quiz/firebase-config.js)** 상단에 덮어씌웁니다:
   ```javascript
   const firebaseConfig = {
     apiKey: "실제_API_키",
     authDomain: "moral-escape-2026.firebaseapp.com",
     projectId: "moral-escape-2026",
     // ...
   };
   ```

### 5단계: 웹 배포하기 (Firebase CLI) (2분)
1. 컴퓨터에 Node.js가 설치되어 있다면 터미널(PowerShell)에서 아래 명령어를 실행합니다:
   ```bash
   npm install -g firebase-tools
   firebase login
   firebase init
   ```
   - 선택 옵션: `Firestore`, `Hosting` 스페이스바로 선택 후 Enter
   - 프로젝트 선택: `Use an existing project` ➔ 방금 만든 프로젝트 선택
   - Firestore 규칙 파일: `firestore.rules` (Enter)
   - Public directory: `.` (현재 폴더이므로 점 하나 찍고 Enter)
   - Configure as single-page app: `Yes`
   - Set up automatic builds: `No`
   - Overwrite index.html: `No` (기존 작성된 파일 덮어쓰지 않도록 주의!)
2. 배포 명령어 실행:
   ```bash
   firebase deploy
   ```
3. 몇 초 후 **`Hosting URL: https://[프로젝트ID].web.app`** 주소가 발급되며 배포 완료! 🎉
